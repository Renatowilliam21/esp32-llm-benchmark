TAREFA

Implementar uma função que determine se um valor float está dentro de
um intervalo inclusivo.

ASSINATURA

bool faixaValida(float valor, float minimo, float maximo);

REQUISITOS

- Retornar false caso valor seja NaN.
- Retornar true quando minimo <= valor <= maximo.
- Limites são inclusivos.
- Não alterar a assinatura.

CÓDIGO CANDIDATO

bool faixaValida(float valor, float minimo, float maximo) {
    if (isnan(valor)) {
        return false;
    }

    return valor >= minimo && valor <= maximo;
}
